This release brings a **major backend refactoring** regarding the RPC architecture and middleware. The **JavaScript Console** now supports long running scripts with realtime progress updates and **import resolution** for `<import>` tags (path, noderef, and classpath resources). We've also improved **CORS** configuration with better input sanitization. **Linux users** can now install via native `.deb` packages. Various bug fixes include improved window close behavior and missing i18n translations.
