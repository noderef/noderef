You can now sign in as a **regular Alfresco user**, not only as an administrator. 🚀

Add a server with a non-admin account and use **Agent**, **Search**, **Insights**, the repository tree, and **Node Browser**. JavaScript Console, Repo Admin, Users & Groups, Model Explorer, Logs, and the System tree stay hidden unless your account has administrator rights.

Rename, Delete, and Permissions in the repository follow Alfresco's own rights on each node. The **Agent** only offers tools your account can use, and it will tell you when a node is off-limits instead of retrying.
