This release introduces **password protection** for Docker deployments, adding an extra access layer before the app UI is exposed in container setups. 🔐

This release also adds full **Spanish** UI support across the app 🌍. We also shipped quality and maintainability improvements. Insights day ranges settings are now persist correctly. Agent internals were refactored for more reliable message handling, and submenu navigation components received usability polish for smoother day-to-day navigation.
