This release adds a metadata panel to **Browse** and lets the **Agent** list Alfresco modules. 🚀

You can now right-click a file or folder in **Browse** and choose **Properties** to inspect its metadata. The panel has tabs for **Properties**, **Aspects**, and **Comments**. Filter properties by name or value, view the node's aspects, and read or add comments without leaving Browse. Existing comment formatting is preserved.

The file list and metadata panel fit their contents and scroll independently. Long names in the panel stay on one line, and MIME type and size appear only for files. The folder context menu also includes **JavaScript Console**, using the folder as the document context.

The **macOS Dock icon** is smaller to better match other apps. The update notification and the update button in **About** also take up less space.
