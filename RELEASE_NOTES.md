This release makes the **Agent** feel live and far more capable. ⚡

Agent now shows progress in real time, with a refreshed timeline and clearer activity messages. We also expanded the Agent with many new Alfresco tools for sites, categories, tags, the trashcan, people, comments, associations, audit trails, repository actions, and version or lock management, so it can handle more repository operations end to end. 🤖

Beyond the built-in **JavaScript Console** libraries, you can now add your own custom JS extensions in the Alfresco repository under `Data Dictionary/NodeRef/js-libs/`. NodeRef loads them as custom AI libraries, so the **Agent** can help with your own Alfresco customizations. See [docs/custom-js-libs.md](docs/custom-js-libs.md) to create your scripts.

We also fixed a handful of bugs and rough edges along the way: connection handling, editor clipboard behavior, modal filtering, and other small improvements.
