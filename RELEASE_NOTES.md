This release contains minor changes. 🔧

You can now **refresh** a folder or site from the Repository tree context menu, so you no longer have to leave the tree to pick up new children.

Servers signed in with **OIDC** now show the same admin server menu as basic auth. 

In the **Node Browser**, the Text Editor action is hidden when the current node cannot be opened as text, instead of sitting in the toolbar as a disabled icon.
